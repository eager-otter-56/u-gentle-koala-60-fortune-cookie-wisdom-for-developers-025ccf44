# Fortune Cookie Wisdom for Developers

A single original fortune-cookie line for a software developer, written by
`main.py` to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

The fortune: you will hunt the bug for a week before it waves at you from the
one line you were proudest of, during the demo. Every senior engineer has
lived it — the defect never hides in the legacy code everyone fears, but in
the line its author bragged about, and it picks the demo to say hello.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
